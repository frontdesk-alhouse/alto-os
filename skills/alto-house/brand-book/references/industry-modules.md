# Módulos de Activation por Industria

Usado en la fase `init` para sugerir las secciones de Activation al usuario.
El usuario puede modificar libremente la lista antes de confirmar.

---

## Base universal (siempre incluida, no se puede quitar)

| Slide | Contenido |
|-------|-----------|
| Business card | Frente + dorso — specs tipográficas (fuente, tamaño, peso por campo) |
| Iconografía | Set de íconos de marca sobre grid cuadrado |
| Patrones | Texturas o patterns repetibles de la marca |

---

## Módulos por industria

### Hospitality / F&B
```
Sugerido: Business card, Menú, Packaging de producto, Señalética, Uniformes
```

| Ítem | Descripción |
|------|-------------|
| Menú | Versión digital (A4) y/o print — tipografía, jerarquía de categorías |
| Packaging de producto | Empaque primario o bolsa de delivery |
| Señalética | Letreros internos, indicaciones, fachada |
| Uniformes / workwear | Camiseta, delantal, gorra — con logo aplicado |

### Fashion / Lifestyle
```
Sugerido: Business card, Etiquetas de producto, Shopping bag, Lookbook page
```

| Ítem | Descripción |
|------|-------------|
| Etiquetas de producto | Hang tag + etiqueta interior — materiales y tipografía |
| Shopping bag | Bolsa de papel o tela con logo |
| Lookbook page | Layout editorial para catálogo o Instagram |

### Professional Services
```
Sugerido: Business card, Membrete, Folder corporativo, Template de presentación
```

| Ítem | Descripción |
|------|-------------|
| Membrete | Hoja carta con header/footer de marca |
| Folder corporativo | Carpeta A4 con logo y datos |
| Template de presentación | Portada + slides internos en PowerPoint/Keynote |

### Tech / Digital
```
Sugerido: Business card, App icons, UI kit mínimo, Email template
```

| Ítem | Descripción |
|------|-------------|
| App icons | Logo en 4 variantes de fondo (cuadrado redondeado iOS/Android) |
| UI kit mínimo | Botones, inputs, colores de estado (success/error/warning) |
| Email template | Header + cuerpo + footer con voz de marca |

### Retail
```
Sugerido: Business card, Empaque de producto, Shopping bag, Señalética punto de venta
```

| Ítem | Descripción |
|------|-------------|
| Empaque de producto | Caja, bolsa, etiqueta adhesiva |
| Shopping bag | Bolsa con logo para la compra |
| Señalética POS | Displays, banners, letreros en tienda |

### Salud / Wellness
```
Sugerido: Business card, Membrete, Empaque de producto, Social media templates
```

| Ítem | Descripción |
|------|-------------|
| Membrete | Receta médica o documento oficial con marca |
| Empaque de producto | Frasco, caja, etiqueta — si aplica |
| Social media templates | Plantillas para contenido educativo/wellness |

```markdown
## Incluidos en el Brand Book

- [ ] Business card
- [ ] Iconografía
- [ ] Patrones

### Seleccionados para este cliente
- [ ] [ítem 1]
- [ ] [ítem 2]
- [ ] [ítem 3]

## Notas
[Cualquier especificación relevante por ítem]
```
